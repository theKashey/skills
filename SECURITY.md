# Security policy

Agent skills can influence filesystem, network, and publishing actions. Treat
instructions that bypass user authority, conceal external effects, expose
sensitive data, or execute unreviewed content as security issues.

Do not include sensitive details in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/theKashey/skills/security/advisories/new)
when it is available. If that form is unavailable, open a public issue that
only requests a private reporting channel.

Include the affected revision, agent or installer, triggering request, observed
behavior, and the least sensitive reproduction that demonstrates the issue.
The maintainer will acknowledge the report before discussing disclosure or a
fix timeline.

Ordinary documentation defects, unclear rules, and non-sensitive incorrect
outputs belong in the public issue tracker.
